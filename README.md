# Matrix Factorization Recommender System

A movie recommender system built on the MovieLens 1M dataset using two
matrix factorization techniques: Singular Value Decomposition (SVD, via
`scipy.sparse.linalg.svds`) and Probabilistic Matrix Factorization (PMF,
mini-batch SGD with L2 regularization, final model is an average of 6
random initializations). Includes an interactive Streamlit dashboard.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Download the [MovieLens 1M dataset](https://files.grouplens.org/datasets/movielens/ml-1m.zip),
   extract it, and place `ratings.dat`, `users.dat`, and `movies.dat` in `data/`.

## Reproducing all results

```
python generate_reports.py     # trains both models, writes processed/ + reports/ (15-25 min)
python make_notebook.py        # builds Movie_Recommender_System.ipynb (then Run All in Jupyter/VS Code)
```

`generate_reports.py` produces the normalized user-item matrix
(`processed/user_item_matrix.csv`), both prediction matrices, all metrics
(`reports/model_metrics.json`), every required plot under `reports/`, and
top-10 recommendation CSVs for three evaluated users.

## Running the dashboard

```
streamlit run app.py
```

(If `streamlit` is not on PATH: `python -m streamlit run app.py`.)
Enter a user ID to see that user's top-rated movies, top-10
recommendations from both models, and a visual SVD-vs-PMF comparison.
Invalid user IDs show an error message instead of crashing.

## Approach

1. Load and preprocess the dataset (`::`-separated .dat files, null/duplicate
   removal), split 80/20 with `random_state=42` (reproducible).
2. Build the user-item interaction matrix from **training data only** (no
   leakage) and normalize it by subtracting each user's mean rating.
3. **SVD**: estimate damped user/item biases, factorize the residual matrix
   with `scipy.sparse.linalg.svds` (k=30 chosen by tuning), reconstruct and
   clip predictions.
4. **PMF**: biased matrix factorization trained by mini-batch SGD (k=128,
   lr 0.01 with 0.99 decay, L2 reg 0.07, 65 epochs chosen via a validation
   learning curve); the final model averages 6 seeds (variance reduction).
5. Evaluate with RMSE on the held-out test set against a bias-only
   collaborative filtering benchmark; generate recommendations excluding
   movies each user already rated.
